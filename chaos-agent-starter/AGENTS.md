# Workspace rules for AI coding agents

- Read README.md and the official CHAOS problem statement before implementation.
- Do not invent requirements; the official problem statement and team-lead instructions take priority.
- Keep frontend code in `frontend/` and backend code in `backend/`.
- Never expose server secrets in frontend code or Vite `VITE_` variables.
- Never claim a feature, test, email, research call or deployment succeeded unless verified.
- Email sending requires explicit user confirmation and must be disabled unless configured.
- Do not store private user history in the cloud until authentication and row-level security are implemented.
- Use small commits and coordinate shared contract changes before editing them.
